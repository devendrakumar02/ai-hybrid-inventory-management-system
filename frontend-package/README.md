# AI Hybrid Inventory - Frontend

## Open in VS Code
1. Open this `frontend` folder in VS Code.
2. Open Terminal.
3. Run:

```bash
npm install
npm run dev
```

The Vite app normally runs at http://localhost:5173.

## Backend URL
The frontend API configuration is intended for the Spring Boot backend at:
`http://localhost:8080/api`

Start the backend separately from IntelliJ IDEA.
